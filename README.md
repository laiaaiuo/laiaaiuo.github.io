# [《最后陪在你身边的人》（成熟陪伴）](https://laiaaiuo.github.io/)

年少时喜欢的人，多半闪闪发光。

后来才明白，能走到最后的人，往往平凡安静。

他不太会说情话，也记不住纪念日；她偶尔脾气不好，还总爱碎碎念。你们都不完美，也没有电影般的桥段。

但你生病时，他会记得买药
他难过时，你会默默做饭
你们很少说“我爱你”，却习惯彼此存在

爱情到最后，会变成生活。

是超市里的两份牙刷，是洗衣机里的混色衣服，是谁顺手倒了垃圾，是谁记得关灯。你们开始讨论的不再是浪漫，而是明天吃什么、假期去哪、未来怎么过。

有人说这叫平淡。

其实这叫长久。

激情会退去，心动会疲惫，但愿意留在同一屋檐下互相照顾，本身就是最深的告白。世界很大，诱惑很多，而你们选择彼此，这件事每天都在发生。

爱情最好的样子，大概不是一直热恋，而是多年以后——

你还在，我也在。
